# 跨障碍擦玻璃机器人 · GlassRobot

基于 **ESP32-S3** 的玻璃墙面清洁机器人，采用**负压真空吸附**贴附于玻璃，通过**手机网页**遥控行走与跨越障碍。

> 全板只有舵机使用硬件 PWM，两颗 L298N 纯数字直驱（不用 EN 脚），
> 联网不依赖路由器 —— ESP32 自建热点，手机连上自动弹出控制页。

---

## 项目背景

高层建筑玻璃幕墙的清洁是人工作业的高危场景。本项目要回答三个工程问题：

1. **怎么在玻璃上不掉？** → 真空吸附 + 急停时"停轮不停泵"
2. **怎么绕过窗框、密封条？** → 推杆 + 末端吸盘组成的跨障执行末端
3. **人站在地面怎么控制？** → 自建 WiFi 热点 + 手机网页遥控

装置底盘有一块圆形真空吸附区保证贴附；本体延伸出的推杆末端是第二个吸盘，
在跨越障碍时由推杆吸盘先吸附固定，本体以它为着力点向上拉起，从而跨过窗框或缝隙。

## 功能

| 功能 | 实现 |
| --- | --- |
| 差速行走 | 前进、后退、原地转向、单轮驱动的 4 种大弧线转弯（8 个方向） |
| 电动推杆 | 按住伸出/收回，松手即停，带换向死区与超时保护 |
| 舵机 | 0°~180°，**逐度缓慢转动**（50°/s），不会瞬间甩到位 |
| 真空泵 | 开关控制，用于吸附玻璃 |
| 2 路继电器 | 开关控制，可接毛刷、喷水、照明等（**高电平触发**） |
| 手机遥控 | SoftAP + 强制门户，连上自动弹页，无需路由器 |

## 引脚分配

| 功能 | GPIO | 说明 |
| --- | --- | --- |
| 左轮 IN1 / IN2 | 4 / 5 | 高 = 正转 / 反转 |
| 右轮 IN3 / IN4 | 6 / 7 | 高 = 正转 / 反转 |
| 推杆 IN1 / IN2 | 15 / 16 | 高 = 伸出 / 收回 |
| 舵机信号 | 10 | 全板唯一 PWM，50Hz |
| 真空泵 | 11 | 高电平吸合 |
| 继电器 1 / 2 | 12 / 13 | 高电平吸合 |

> 已避开 ESP32-S3 敏感引脚：GPIO 0/3/45/46（strapping）、19/20（USB）、
> 26~32（Flash SPI）、33~37（八线 PSRAM）。

### 接线要点

1. **共地第一**：两颗 L298N 的 GND、ESP32 的 GND、电池负极必须全部相连。
2. **ENA/ENB 跳线帽必须插着** —— 本方案不用 EN 脚，跳线帽短接即常使能全速。
3. **5V 只能取一路**：最多用一颗 L298N 的 5V 给 ESP32 供电，切勿把两颗的 5V 并联。
4. **舵机电源必须独立**，但信号线与 GND 要和 ESP32 相连，否则会拉低电压导致复位。
5. 电机转向反了 → **对调该电机 OUT1/OUT2 两根线**，不要改程序。

## 快速开始

### 1. 环境

- Arduino IDE 2.x
- `esp32 by Espressif Systems`（3.1.x 或更新）
- **无需第三方库**，全部使用 ESP32 core 自带组件

### 2. 开发板设置

| 选项 | 值 |
| --- | --- |
| 开发板 | ESP32S3 Dev Module |
| PSRAM | N16R8 → OPI PSRAM；N8R2 → QSPI PSRAM |
| USB CDC On Boot | **Enabled**（否则串口无输出） |
| 分区方案 | 默认；报 too big 则选 Huge APP (3MB No OTA) |

### 3. 烧录与连接

```
烧录 → 打开串口监视器（115200）确认初始化日志
     → 手机连接热点 GlassBot-XXXX（密码 12345678）
     → 控制页自动弹出；未弹出则浏览器打开 http://192.168.4.1
```

### 4. 串口分步调试（不连手机也能测）

在串口监视器发送单字符：

| 字符 | 动作 | 字符 | 动作 |
| --- | --- | --- | --- |
| `f` | 前进 | `u` | 推杆伸出 |
| `b` | 后退 | `d` | 推杆收回 |
| `l` | 原地左转 | `s` | 推杆停止 |
| `r` | 原地右转 | `0`~`9` | 舵机 0°~180° |
| `x` | 停车 | `v` | 舵机自检 |

## 差速转向：8 个方向的由来

车轮只有 **正转 / 反转 / 停** 三种状态，两轮组合共 3×3=9 种，去掉"停停"即 8 个真实动作：

| 左轮 | 右轮 | 车身运动 | 界面名称 |
| --- | --- | --- | --- |
| + | + | 直线前进 | 前进 |
| + | 0 | 绕右轮前滚 | 右前弧 |
| + | − | 原地顺时针转 | 原地右转 |
| 0 | − | 绕右轮后退 | 右后弧 |
| − | − | 直线后退 | 后退 |
| − | 0 | 绕左轮后退 | 左后弧 |
| − | + | 原地逆时针转 | 原地左转 |
| 0 | + | 绕左轮前滚 | 左前弧 |

> **差速车没有"横移"自由度。** 斜方向的本质是一个轮子驱动、另一个轮子刹住，
> 车体绕刹住的那个轮子画弧 —— 不是平移。
>
> 运动学：`v = (vL + vR) / 2`，`ω = (vR − vL) / L`（L 为轮距）

## 安全机制

| 机制 | 参数 | 作用 |
| --- | --- | --- |
| 行走看门狗 | 700ms | 指令中断 → 自动停车，防手机锁屏后跑飞 |
| 推杆看门狗 | 800ms | 同上 |
| 推杆超时 | 25s | 连续运行超时 → 锁定，需松手解锁 |
| 换向死区 | 150ms | 先断开再反转，防 L298N 直通 |
| 切后台停车 | — | 锁屏、来电、切后台立即停车 |
| 上电安全初始化 | — | 先写无效电平再切输出，防继电器误吸合 |
| 停车刹车 | — | 两 IN 同高，绕组短接，玻璃上不打滑 |

> 急停**只停行走、推杆、舵机，不停真空泵** —— 泵一停装置就会从玻璃上掉下来。

## HTTP 接口

所有接口均为 GET，可直接用浏览器或脚本调用。

| 接口 | 参数 | 作用 |
| --- | --- | --- |
| `/api/drive` | `l`, `r` ∈ {-1,0,1} | 左右轮状态 |
| `/api/move` | `d` = f/b/l/r/x | 方向码控制 |
| `/api/act` | `v` ∈ {-1,0,1} | 推杆收回/停/伸出 |
| `/api/servo` | `a` = 0~180 | 舵机目标角度 |
| `/api/pump` | `on` = 0/1 | 真空泵 |
| `/api/relay` | `id`=1/2, `on`=0/1 | 继电器 |
| `/api/estop` | — | 急停 |
| `/api/status` | — | 读取全部状态（JSON） |
| `/api/reboot` | — | 重启 |

`/api/status` 返回示例：

```json
{
  "ip":"192.168.4.1", "ssid":"GlassBot-A1B2", "cli":1, "up":185,
  "l":1, "r":1,
  "servo":42, "svT":90, "svMove":1,
  "act":0, "blk":0,
  "pump":0, "r1":0, "r2":0,
  "heap":210344
}
```

> `drive` 与 `act` 受看门狗约束，自己写脚本时需约每 0.5 秒重发一次指令。

## 关键实现说明

### 舵机为什么是"逐度移动"

舵机内部是闭环控制，它只会**以自身最大速度冲向目标脉宽**，硬件上没有调速概念。
所以本项目把角度整数化，一次只走 1 度、每度 `delay` 一次：

```cpp
_angle += (target > _angle) ? 1 : -1;
writePulse(_angle);
delay(SERVO_STEP_DELAY_MS);      // 默认 20ms/度 -> 50°/s
```

速度由 `SERVO_STEP_DELAY_MS` 决定（`20` → 50°/s → 180° 约 3.6 秒）。

这段阻塞循环放在**独立的 FreeRTOS 任务**里，所以 `delay` 不会卡住 Web 服务，
转动途中网页仍可响应、可急停、可随时改目标。

### ESP32-S3 的 LEDC 陷阱

ESP32-S3 的 `SOC_LEDC_TIMER_BIT_WIDTH` 只有 **14 位**（老 ESP32 是 20 位）。
若按常见例程请求 16 位分辨率，`ledcAttach()` 会**静默返回 false**，引脚上一点波形都没有。
本项目固定使用 14 位并检查返回值 —— 这是"舵机完全没反应"的真正原因。

## 故障速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 舵机完全不动 | 供电不足 / 引脚错 | 独立 5V 供电并共地；串口发 `v` 自检 |
| 某个轮子不转 | ENA/ENB 跳线帽没插 | 插上跳线帽 |
| 轮子转反 | 电机线接反 | 对调该电机 OUT1/OUT2 |
| 一开电机板子复位 | 未共地 / 电池没电 / 舵机抢电 | 共地、充电、舵机独立供电 |
| 网页打不开 | 手机走了移动数据 | 关流量，打开 `http://192.168.4.1` |
| 继电器反着来 | 触发极性不符 | 改 `RELAY_ACTIVE_HIGH` |
| 上传卡在 Connecting | 未进下载模式 | 按住 BOOT 再上传 |
| 串口无输出 | USB CDC 未开 | 设为 Enabled 重新烧录 |
